Reachy Alive

A Reachy Mini that feels alive, even when idle.

Early, and actively developed

It breathes, and every now and then it yawns, stretches, sneezes or hiccups, on its own, like a creature rather than a machine waiting for orders.

Try it on your robot

  1. Install it

    In Reachy Mini Control, find Reachy Alive in the app store and install it.

  2. Run it

    The robot starts breathing, and plays an idle move every 20 to 30 seconds.

  3. Play with it

    Its page opens next to Reachy Mini Control. Play any move on demand, or set how long the robot waits between idle moves.

Teach it a new move

Reachy Alive is open source, and built to grow one move at a time. Pick the way that suits your move, not the one you already know.

Write it in code

For motion that's simple to describe: rise, hold, come back. No robot needed.

Record it by hand

For organic motion: move the head yourself in Marionette, and it captures everything.

Both

Record the head, code the antennas, for when you run out of hands.

Everything runs in simulation, so you can start without a robot. Read the guide to making a move, then open a pull request with a short video of your move.

How it works

The code is organized like a nervous system. Breathing and idle moves live in the brainstem; reflexes and deliberation come next, each in the region that fits its speed. One control loop drives the robot, and nothing is allowed to block it: the robot keeps moving while it thinks.

Where it's going

  1. It breathes

    Breathing, idle moves, and a page to play them. Today.

  2. It sees

    Camera, motion and faces: the robot starts to perceive the room.

  3. It reacts

  4. It thinks
